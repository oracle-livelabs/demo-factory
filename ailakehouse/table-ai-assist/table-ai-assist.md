# Using Table AI Assist in Data Studio

## Introduction

**PeakGear** receives demand signals from a social-media partner. The `PRODUCT_HINTS` field can contain several SKU IDs and product names, which makes it difficult to identify the product in each message.

In this scene, use Table AI Assist to create a new table with a `SKU_ID` column containing the first SKU from `PRODUCT_HINTS`. The exercise uses a regular expression, and Table AI Assist helps generate the SQL.

Data Studio's **Table AI Assist** uses **OCI GenAI** to suggest the SQL for extracting the SKU.

Estimated Time: **15 minutes**

### Prerequisites

**Important:** Complete **Real-Time Streaming Ingest** before starting this scene.

### Objectives

In this scene, you will:

- Inspect demand signals that need cleanup.
- Use Table AI Assist to create a corrected table.
- Ask AI Assist to suggest SQL for extracting a SKU.
- Review and save the result.


## Task 1: Open Table AI Assist

Open the **Table AI Assist** demo:

1. In the left sidebar, expand **Process**.
2. Select **Table AI Assist**.

## Task 2: Open Data Studio from the LiveStack page

Open Data Studio from the LiveStack page:

1. Click **Open Data Studio**.
2. Sign in to Database Actions with the displayed PG username and password.

## Task 3: Open the data-loading workflow

1. In Database Actions, open **Table AI Assist**.
2. Select **Data Load**.
3. Click the **Load Data** tile to start a new loading job.

## Task 4: Create a new recipe for BRONZE\_DEMAND\_SIGNALS

1. Search for **bronze demand** in the search field.
2. Click **New Recipe**.

## Task 5: Review the preview data

Pause to review the data preview. The rows come from the real-time demo. The `PRODUCT_HINTS` column contains several SKU IDs and product names, and the first SKU is the relevant one for this exercise. Create a new table with a `SKU_ID` column containing that SKU.

## Task 6: Edit the Recipe

Prepare the new recipe:
  
1. Change **Target Type** to **Create Table**.
2. Set **Target Name** to **BRONZE\_DEMAND\_SIGNALS\_FIXED**.
3. Click **Add Step** and select **Add or Replace Column**.
  
A window opens. OCI GenAI analyzes the table and its metadata and suggests a change.
  

## Task 7: Ask AI to generate SQL

Ask AI to generate SQL for the new `SKU_ID` column:
  
1. In the text box **Ask AI to generate SQL**, paste this question:
   
   ```text
extract the first SKU inside quotation marks in the PRODUCT_HINTS column
    ```

2. Click **Ask AI**.
3. Review the result. The left side shows the explanation. The right side shows the SQL generated by AI.
4. Compare the generated SQL with: *REGEXP_SUBSTR("PRODUCT_HINTS", '"(.*?)"', 1, 1, NULL, 1)*
5. If the SQL differs, edit it or refine the prompt.
6. Rename the column to **SKU_ID**.
7. Click **Save**.

## Conclusion: Business Outcome

Table AI Assist helps PeakGear turn messy demand-signal text into a column that other data workflows can use. The source data remains available, while the new table adds a `SKU_ID` that makes product references easier to match.

PeakGear can then use the corrected data in later processing and product or demand analysis.

The Table AI Assist scene is complete.
